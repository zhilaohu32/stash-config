# Stash 简化配置

此配置使用一个 `Manual` 策略组选择订阅节点：国内 IP 直连，其他流量走所选节点。`AI` 是旧覆写兼容入口，默认指向 `Manual`。

## 使用

1. 将 `local.example.stoverride` 复制到私密覆写，在 `ProviderA` 填入完整订阅地址；示例地址不可直接使用。
2. 在 Stash 导入 `Stash.yaml` 并启用私密覆写，在 `Manual` 选择节点；各设备单独登录 Tailscale 的 `beans` 节点。
3. 更新主配置后，旧覆写中的个人规则仍可能优先影响分流。若要严格使用简化规则，请移除旧覆写中不再需要的自定义规则，并保留订阅及 Tailscale 节点。

`ts.net` 和 `100.64.0.0/10` 指向 Tailscale；其他已批准的子网路由可能需要按实际网段增加规则。国内判断依据 GeoIP，并非所有国内域名都保证直连。

Secret Gist 的链接可被任何持有者访问，请像订阅地址一样保管。更新 Gist 后需在 Stash 更新覆写。导入前备份现有配置；此配置未经实际客户端测试。
